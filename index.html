What is cloud computing?

Cloud computing provides on-demand access to computing resources such as servers, storage and networking over the internet, without needing physical hardware in a local office or laboratory.

What is AWS?

AWS (Amazon Web Services) is a cloud platform that offers a large number of scalable services for hosting applications, data storage and content delivery.

What is EC2?

EC2 is Amazon Elastic Compute Cloud, which lets developers launch virtual machines (VMs) in the cloud with configurable CPU, memory and networking resources.

What is Nginx?

Nginx is a high-performance web server used to serve static websites and applications efficiently across the internet.

How website hosting works

The user opens the EC2 public IP in a browser. Nginx receives the request, reads the static files from /var/www/html and delivers them as HTML, CSS and JavaScript to the client.

Optional future architecture

S3 and CloudFront are optionally proposed for scalable media delivery and accelerated content distribution, but they are not required for this academic static frontend deployment.

About CineVault

Project Details

  • Project Name: CineVault
  • Project Type: Cloud-Based Video Subscription Platform
  • Frontend: HTML, CSS, JavaScript
  • Cloud Platform: Amazon Web Services
  • Virtual Machine: AWS EC2
  • Operating System: Ubuntu Linux
  • Web Server: Nginx
  • Hosting Type: Static Website Hosting on Cloud VM

Objective

CineVault demonstrates a premium streaming service interface with a static frontend that can be deployed directly on an AWS EC2 Ubuntu instance using Nginx. This project is designed for academic learning about cloud hosting, frontend web development and static deployment workflow.
